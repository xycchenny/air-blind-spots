# How far is your nearest air monitor?

An interactive map for COGS 137 Case Study 02. Pick any U.S. county to see how far its center is from the nearest PM2.5 monitor in our 2008 dataset, and what that monitor read.

**Live page:** https://xycchenny.github.io/air-blind-spots/

- `index.html` — the page
- `data.json` — county shapes (U.S. Census boundaries via `us-atlas`), each county's distance to its nearest monitor, and the 876 monitors' locations and 2008 yearly averages from the course dataset

Distances are straight-line miles from each county's geographic center. The dataset may not include every monitor operating in 2008. Not live air quality: for today's reading, see airnow.gov.
